# Registry (bin/llm-api.py, port 8081) - the HTTP catalog and MCP for agents.
#
# Deliberately separate from the chat UI's environment: Open WebUI pulls in over
# 500 packages, and an upgrade there moves fastapi/pydantic/mcp. With both in one
# environment, an 'llm update ui' could take every agent offline.
# lib/llmreg.py itself needs nothing but the standard library.
fastapi
uvicorn

# 2.x only, and not by preference: mcp 2.0 renamed 'mcp.server.fastmcp' to
# 'mcp.server.mcpserver', dropped the module-wide get_context() and moved the
# transport settings out of the constructor. bin/llm-api.py uses all three, so
# there is no range that covers both series - see docs/API.md.
mcp>=2.0.0,<3
